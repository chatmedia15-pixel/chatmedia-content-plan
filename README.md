# Content Plan — Chatmedia

Aplikasi internal untuk perencanaan konten & analitik Instagram multi-brand.

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS
- React Router v6
- TanStack Query
- Supabase (Postgres + Auth + Edge Functions)
- Gemini API (via Edge Function)

## Setup

### 1. Clone & install

```bash
npm install
```
